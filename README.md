# 🔥 Friendly Fire

แอปเล็ก ๆ สำหรับเพื่อนสองคน: จดงานของตัวเอง ติ๊กเมื่อเสร็จ หรือกด **"เสร็จแล้ว!"** แล้วเครื่องของอีกฝั่งจะเด้งบอกพร้อมเสียง ส่ง 🔥 👏 💪 😎 กลับไปเชียร์ได้

## ติดตั้ง

1. ดาวน์โหลด **[FriendlyFire.exe](https://github.com/Zerocasidor/FriendlyFire/releases/latest/download/FriendlyFire.exe)**
2. ดับเบิลคลิกเปิด ถ้า Windows ขึ้นว่า *"Windows protected your PC"* ให้กด **More info → Run anyway** (แอปไม่มีลายเซ็นบริษัท เลยขึ้นแบบนี้ครั้งแรกครั้งเดียว)
3. ใส่ชื่อ แล้วเลือก
   - **สร้างคู่ใหม่** → จะได้รหัสเชิญ `FF-...` ส่งให้เพื่อน หรือ
   - **ใส่รหัสเชิญจากเพื่อน** → วางรหัสที่เพื่อนส่งมา

ถ้าต่างคนต่างกดสร้างคู่ไปแล้ว: คลิกขวาไอคอน → **รหัสเชิญ...** → ช่อง *ใส่รหัสเชิญจากเพื่อน* แล้วกด **เข้าร่วม** (คนเดียวพอ)

แอปจะอยู่ที่ไอคอนเปลวไฟมุมขวาล่าง (ดับเบิลคลิกเพื่อเปิด) เปิดพร้อม Windows ได้ (ปิดได้ในเมนูคลิกขวา) และ **อัปเดตตัวเองอัตโนมัติ** เมื่อมีเวอร์ชันใหม่

## ใช้งาน

- **งานของฉัน**: พิมพ์งานแล้วกด Enter, ติ๊กเมื่อเสร็จ → เพื่อนเด้ง; งานที่ติ๊กแล้วหายเองใน 24 ชั่วโมง หรือคลิกขวาเพื่อลบ (งานที่เสร็จแล้วยังอยู่ที่เครื่องเพื่อนจนหมดเวลาฝั่งนั้น)
- **งานของเพื่อน**: ดูอย่างเดียว งานที่เสร็จแล้วจะค้างไว้จนคุณเปิดหน้าต่างเห็น แล้วหายเองหลังจากนั้น 24 ชั่วโมง (คลิกขวา → ลบ ได้ทันที เฉพาะเครื่องคุณ)
- **ลากงาน**: ลากขึ้นลงเพื่อเรียงลำดับ หรือลากไปวางฝั่งเพื่อนเพื่อส่งงานให้ เพื่อนจะเห็นเป็นแถบสีเทา กด ✓ สีเขียวเพื่อรับ หรือ ✗ สีแดงเพื่อทิ้ง
- **เสร็จแล้ว! 🎉**: บอกเพื่อนว่าทำอะไรเสร็จ โดยไม่ต้องอยู่ในรายการ

## ความเป็นส่วนตัว

ข้อความส่งผ่าน [ntfy.sh](https://ntfy.sh) (บริการแจ้งเตือนฟรี) ในช่องที่ตั้งชื่อจากรหัสเชิญ ใครรู้รหัสก็อ่านได้ จึงส่งรหัสให้เพื่อนคนเดียว และไม่ควรใส่ข้อมูลลับในงาน ntfy เก็บข้อความไว้ประมาณ 12 ชั่วโมง แอปจึงส่งรายการงานซ้ำทุก 6 ชั่วโมง

## สำหรับคนพัฒนา

- `build.ps1` คอมไพล์ด้วย C# compiler ที่มากับ Windows (.NET Framework 4) ไม่ต้องติดตั้งอะไรเพิ่ม
- `release.ps1 <เวอร์ชัน> "<สิ่งที่เปลี่ยน>"` build + push + สร้าง GitHub release แอปทุกเครื่องจะอัปเดตเอง
- ทดสอบสองเครื่องในเครื่องเดียว: `FriendlyFire.exe -Data <โฟลเดอร์> -Name <ชื่อ> -Code <รหัส>`
